# 统一机器人能力描述：验证记录

本轮将模板、导入文件、库模型和组合机器人的能力信息收敛到编译后模型的同一份描述。
MCP、脚本和查看器共享该描述，保留旧工具签名与返回字段。
控制算法和单项操作成功率未调整。
契约和缓存边界见 [CAPABILITIES.md](../CAPABILITIES.md)。

## 实现与兼容

- 冻结的结构描述记录真实 TCP、可驱动的机械臂、夹爪执行器、原始控制、传感器及原有模式适配。
- 移动描述复用运行控制器的绑定和速度公式，查询不创建控制器、求解器或策略模型，不推进实时物理。
- 活动控制器速度、载荷限制、当前水中阻力、保存的步态和策略卡片按原有规则叠加。
- 无 TCP、没有驱动关节、独立夹爪、未配步态的人形和关节不匹配的保存步态都有明确不可用结果。
- 脚本保留旧服务器回退，增加能力快照、显式刷新及逐臂夹爪入口。
- 查看器使用能力选择驾驶、手柄和模式入口；模型版本、网格加载缓冲和仅广播更新覆盖了多客户端同步边界。
- `move` 和 `run_script` 广告定义逐字段一致，旧返回字段均保留；转弯移动前后都为 0.559 m。
- 原有类别、模型名、机械臂列表和速度字段保留；能力字段是增量信息。

## 真实 CLI、MuJoCo 和 Chrome

通过实际安装的 `robotforge mcp` 子进程测试，不使用伪造服务或物理结果。
模板机械臂、导入 URDF 底盘、导入 URDF 机械臂、带臂底盘、独立夹爪和零已学步态的自制机器人共六个条目，在 MCP、HTTP 场景和脚本中能力一致。
脚本使用规范化 JSON 的 SHA-256 对每个完整能力值逐一核对，保留现有 6000 字符输出上限。

| 检查 | 观察结果 |
| --- | --- |
| 导入 URDF 底盘，0.2 m/s、1 s | 平移 0.176 m。 |
| 组合底盘，0.15 m/s、1 s | 使用已有 JGA25 电机、8 cm 轮半径配置，平移 0.137 m。 |
| 组合机械臂脚本 | 解析到 `carrier/arm`，打开夹爪并到达目标附近，最大坐标误差 10.7 mm。 |
| 导入 URDF 机械臂 | 通过实际 `move_arm` 操作，最大坐标误差 18 mm。 |
| 实时查看器 | 观察组合机器人移动，驾驶与手臂的手柄配置为 `both`，独立夹爪不显示驾驶入口。 |
| 真实库模型 | 加入缓存的 Panda，场景与能力更新正常。 |
| 人为延迟网格响应 | 加入 Panda 后阻塞网格响应，再保存步态；解除阻塞后保留最新能力信息。 |
| 两个查看器 | 删除保存步态并连接第二个查看器，两个页面均刷新为不可移动。 |
| Chrome 运行 | 截图已检查，没有 JavaScript 错误；测试创建的两个 Chrome 进程均已关闭。 |

默认小型底盘加臂后的早期短程尝试未达到验证脚本原定的位移阈值。
保留了该尝试，没有更改生产控制参数或将其用作成功率调参样本。
上述组合通行结果只适用于记录的电机、轮径与载荷配置，能力支持不表示任意配置都有同等运动表现。
