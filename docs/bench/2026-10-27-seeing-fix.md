# Seeing 暗光掩码回归修复（2026-10-27）

PR31 的唯一完整回归失败在原版 main 上也复现：白平衡与清理同时开启时，十次观察中九次只找到红方块，一次把同一个方块分成两块。
原断言、随机种子、相机、光照和物理配置均保持。

## 根因与修复

实际 MuJoCo 相机画面中，暗光噪声在红方块顶面和侧面的交界形成细缝。
原 `vision.clean` 只执行 3×3 开运算，去掉噪点但不能填合细缝；在失败帧中留下 518 和 287 像素的两个连通区域。
增加可选的 `fill_gaps=True`，在开运算后执行一次 3×3 闭运算，再做连通区域识别。
Seeing 的清理选项启用填合，默认 `clean(mask)` 仍完全保留旧的开运算行为。
不使用物体标签合并结果，不放宽颜色阈值，不修改噪声，不增加重试，也不降低旧测试断言。

闭运算可能连接相隔不超过两个像素的有效区域，这是该方法的边界；本轮只在清理开关启用时使用，其他视觉调用默认不变。
新增用例检查一、二、三像素缝隙的不同处理、独立对象不粘连、噪点、输入不变和图像边界。

## 实际画面对照

修复前后按原用例顺序执行实际物理步进与离屏渲染。
白平衡与清理两项都开启的十次观察，其 RGB、加噪后输入和几何标签逐像素相同。
原失败帧清理后得到 819 像素的一块，顶面与侧面重新连通。
四种开关组合的单独红方块计数从 `0, 0, 0, 9` 恢复为 `0, 0, 0, 10`。
保留原调度；相邻观察有可能复用一帧，不把它表述为十张独立采样画面。

原始图片、掩码、数组、比较和命令回执保存在仓库外的 `robotforge-evidence/2026-10-27-seeing-fix/`。
定向 `tests/test_seeing.py` 与 `tests/test_vision.py` 共 45 项通过，包括未修改的原失败用例。
