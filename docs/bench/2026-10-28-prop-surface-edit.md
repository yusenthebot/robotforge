# 已有道具外观探索与回归修复（2026-10-28）

球、方块和圆柱现在可在“已有道具 → 外观”中切换原始外观、塑料、木材和钢，沿用共享材质。
独立的可选 `surface_material` 保留原物理 `material`、密度、质量、摩擦、碰撞和磁吸；叶片、瓶盖等装饰保持各自材质。
“应用并重置”保留当前根姿态、关节和控制目标，清零速度与时间并暂停；任务和控制器内部状态按现有重建流程重置。
服务端同值重选不重建、不重置时间或代次，并保留旧 Undo；真正修改后的单次 Undo 沿用撤销时的最新姿态，不倒放运动。
保存、复制、布局恢复、刷新和 Reset 保留覆盖；旧世界省略该字段，MCP 工具参数不变，本地 Python 显式传 `surface_material=None` 可清除覆盖。
组合桌子、机构和机器人不开放该入口；柔性体及带不支持钩子的世界暂不支持应用外观修改，提交时会拒绝。

## 真实场景与录像

Malo 工作坊、Go2 仓库和 Panda 工作台各两种固定镜头，逐场景比较 486 项模型/状态数组；Malo 仅有隔离目录的路径和地址差异，对应网格 SHA 完全相同，其他两组全部数组相同。
完整场景 JSON 仅新增 4/35/4 个支持道具的 nullable 外观字段；镜头误差小于 1e-10，视口、DPR、几何、绘制次数、材质资源和程序数保持。
六幅图 RGB 平均绝对差为 0.0000226–0.000734（8 位通道），最大单通道差 32；普通/细节原图均检查，未见明显外观变化，但不是像素逐字节一致，差异原因未单独定位。
单次 warm 采集计时含编译、Chrome 启动、两次导航和暂停/重置准备，不作为首次用户加载或普遍提速证据。
相对库网格路径和隔离生成网格目录的两次验证助手失败均保留；路径绑定修正不涉及产品代码，最终模型/XML/网格/世界/助手输入哈希在报告时再次核对。

三段实际 Chrome 中文流程均执行四次外观切换、无操作重选、撤销、恢复原始、存档、换图恢复、真实刷新、机器人操作和 Reset；验证脚本在录像期间未直接写姿态或手动步进。
脚本镜头初始化和描述性绘制探针在录像外；录像中的 Focus、选择器、点击和驾驶/关节操作为可信原生输入。
