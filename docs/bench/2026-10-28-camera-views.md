# 共享观察与布置视角（2026-10-28）

底部新增“视角”入口，提供俯视、正视（世界 −Y）、侧视（世界 +X）与一次返回原视角，让已有机器人、道具和地形编辑共用可重复的观察方向。
保留当前观察目标、距离与透视，弧线切换避免正反视角间穿过观察目标；系统减少动态效果时直接切换。
俯视用 OrbitControls 的微小极点容差保持世界 +Y 向上，正视并不代表每个机器人的自身正面。
没有自动完整取景、镜头避障或正交测量；先用“看全部”或手动调整观察范围。

## 编辑边界

打开视角菜单会松开驾驶与物理拖拽、使旧手势失效并清空旧落点；关闭菜单的画布轻点只收起菜单。
视角切换动画期间不接受落点，之后重新选择支撑面；Escape 优先收起菜单并保留编辑流程。
修复原生鼠标按住后通过键盘打开菜单、再释放旧鼠标导致误添加的问题，保留修复前失败与修复后测试。
返回只保存首次预设前的一份位置与观察目标，不恢复自动跟随；手动转动仍可返回。
添加、编辑、Undo、课程和地图等场景重建会清空这份临时记录，布局不保存镜头。
接口、世界格式、物理模型和材质保持兼容；本轮提升观察与创作体验，没有新的着色观感或单项动作成功率变化。

## 实录、控制与保留失败

三组前后实录使用相同最终服务源码，原版服务冻结上游静态树，候选服务冻结最终静态树，并核对实际获取的 app.js 哈希。
初始镜头在录像前设定，录像内使用可信原生鼠标／触摸输入：观察三方向并返回，再添加道具、移动既有 dock 或台面 marker，最后撤销。
Go2 两组均在录像前调整镜头以覆盖完整局部 dock，不是产品自动取景能力；这段不以画面外的机器人为观察对象。
基线手动转相机使用读出姿态后计算的理想角度，输入轨迹不记录 pointermove，不能从事件数或片长声称人工效率或学习收益。
最终六段全部完整解码，主进程检查六张联系图的 36 个解码样本及三个俯视固定图；不是逐帧视觉或动态动作成功率认证。
俯视可读平面位置，侧视可读桌面／坡道高度；本轮没有新增共享着色观感提升。
每段观察期间 482 项完整模型数组及 qpos／qvel／ctrl 保持，撤销后世界配置恢复。
跨两组仅 Malo 隔离网格路径／地址不同，解析后网格文件哈希相同；其他模型和状态数组相同，返回眼点／目标误差小于 1e-5。
返回不保证所有画布逐像素相同，保留 JSON 中实际像素比较结果。

初版采集曾遇暂停就绪条件、readback 和中断问题，v1–v4 原始材料均保留；v4 对应旧 dee8 产品，不能改称最终 d454 实录。
原版 v3 在编辑前也出现 GL1282；独立同步诊断确认可见 head RGB 管线的 live PIXEL_PACK_BUFFER 与 TypedArray readPixels 冲突，同帧解绑后读回非零且无错，再恢复完全相同的 buffer。
v2 没有保存错误编号，不能追溯声称它也是同一 GL1282 原因。
最终外部采集协议同步保存／解绑／读回／恢复并检查各阶段错误，产品 debug pixels 钩子原样保留；这是测量边界修正，不是产品 GL 修复或每帧无错证明。
测试格式与首次漏选 browser 标记导致的零用例调用也保留，不当作产品失败或通过。
