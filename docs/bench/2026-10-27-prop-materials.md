## 行为与兼容性

已有物体的 `material` 现在传入共享视觉层：塑料、木材、钢分别复用 `rf_shell`、`rf_wood`、`rf_metal`。
木积木、木障碍墙不再被普通形状的塑料外观覆盖；颜色和几何保持原样，罐盖、叶片、果柄等装饰不随主体替换。
材质绑定在几何缓存之外完成，避免材质之间污染缓存。未指定材质的名字派生外观、导入机器人的原生材质继续保留。

查看器放置球、积木、柱子或障碍墙时可选“默认／塑料／木材／钢”；连续放置保留选择，新选道具恢复默认，提交期间禁用。
默认请求不发送新字段；桌子、机器人、模型、移动、复制和起点调整不显示选择器。复制与存档继续保留原材质。
连续放置、撤销和保存恢复是已有能力，本轮增加材质选择及其跨连续放置的保留。线框预览仍只表达尺寸和落点。
材质沿用已有密度与钢材磁吸定义；UI 道具已有的显式质量仍按原预设和尺寸缩放，不因选择钢材额外增重。摩擦、碰撞和动作控制规则未修改。

Malo、Go2、Panda 三个世界使用相同配置、暂停起始姿态、Studio 光照、相机位置、投影、1280×800 窗口和 DPR；显式固定裁剪距离 0.01/200。
`baseline-v2/` 与 `candidate-v2/` 各保存普通视距和近景。2,474 项比较通过：每组 444 个非视觉模型/网格/状态数组完全一致；原生机器人材质按名称逐项一致。
每组仅预期的木材、钢材主体绑定变化；材质名称、整数 ID 与地址记录作语义比较。实际相机误差为零。

普通视距可见木纹和金属高光变化；钢球也更暗，不以更亮作为质量标准。机器人、地形和已有仓库构件没有作为本轮新视觉收益来计数。
三组各有前后约 3.63–3.67 秒的实际查看器镜头，位于 `orbit-before/`、`orbit-after/`。
这是暂停场景的脚本镜头，画面有明确标注；不是用户输入或移动机器人演示。
每段至少 213 帧原始记录，时间戳严格递增，覆盖超过 3.53 秒，轨迹实际到达正负约 0.22 rad；暂停前后 qpos/qvel/ctrl 不变。

`workflow-v2/workflow.mp4` 是 20.633 秒真实原生操作：木障碍墙、连续钢块、撤销、Malo 驾驶与松键停止、保存、切图恢复、重置。

## 保留的失败与边界

首次对比缺少模型名称字节，自动取景也留下不同裁剪距离；修正采集元数据并显式固定相机后重新采集，没有放宽相机匹配来通过。
第一次浏览器批次在三个失败后中断：桌面方向键没有改变 macOS 原生下拉框，手机新落点在画布外。
原生文字输入诊断确认可信 change 后，桌面改用本地化 typeahead；手机保留原生方向键并验证最终可信事件，落点增加实际画布命中断言。
随后一次测试捕获的是手机中间选择事件，驱动改为核对全部可信事件和最终值；14 项搭建流程及最终完整套件通过。
第一次工作流因放置栏遮挡点击点而失败；第二次只在录制前调整相机，原失败帧和 manifest 保留。
这些驱动与采集修正没有改产品断言、点击重试或自动放置；源码在完整执行及后续检查期间保持冻结。
原工作目录十三项未提交工作保留。小功能成功率没有作为本轮开发或验收目标。
