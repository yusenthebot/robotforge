# 第 2 课 开一台小车：两个轮子怎么转弯

目标：开一台两轮差速小车，能解释为什么两个轮子转速不同，小车就会转弯。

## 你可以这样说

> 给我一台两轮小车，开着它转一圈，告诉我它是怎么转弯的。

## 你会看到

agent 放好一台小车并打开查看器，你可以直接用键盘 W A S D 开它。
agent 先让它以 0.3 米每秒直行 3 秒，报告走了多远（作者电脑上 0.86 米）。
再让它一边前进一边以 1 弧度每秒左转 3 秒，报告转了多少度（大约 151 度）。
最后 agent 直接给左右轮下命令：左轮每秒 4 弧度，右轮每秒 8 弧度，小车画出一段向左的弧线。

## 背后的道理

差速小车只有两个带电机的轮子，后面一个万向球撑着。
两个轮子一样快，小车走直线；右轮比左轮快，小车往左转；一前一后反着转，小车原地打转，就像坦克。
速度的单位是米每秒，转向用角速度，单位是弧度每秒，正数表示向左（从上往下看是逆时针）。
朝向用角度报告，0 度朝向 x 轴正方向。
理想情况下，1 弧度每秒转 3 秒应该转 172 度，实际只有 151 度左右。
差的那部分来自起步加速和轮子打滑，这就是为什么机器人要靠测量知道自己在哪，而不是靠假设。

## 自己动手

在查看器里用 W A S D 开一圈，试着让小车停回出发的地方。
让 agent 在路上放一个箱子（`add_object`），再绕过去。

## 怎么算成功

直行的 `distance_m` 接近速度乘时间（0.3 米每秒乘 3 秒约 0.9 米）。
转弯的 `turned_deg` 是正数（向左），并且小于理想值 172 度。

## 挑战

开一个完整的圆回到起点，看看最后离起点差多少，想一想差在哪里。
