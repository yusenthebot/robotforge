# 第 5 课 传感器和相机：机器人眼里的世界

目标：从机器人自己的摄像头看世界，并在它转弯时读懂 IMU 的读数。

## 你可以这样说

> 让我看看小车摄像头里的画面，再告诉我它的传感器读数是什么意思。

## 你会看到

agent 放一台小车，前方放一个红球，左前方放一个蓝箱子。
它列出小车的传感器：`rover/accel`、`rover/gyro`、`rover/orientation`，以及前置摄像头 `rover/front_cam`。
从小车的摄像头拍一张图：红球在画面正中，蓝箱子在左边。
再从正上方拍一张，对比“我们看到的世界”和“机器人看到的世界”。
让摄像头找红色的东西（`observe(find="red")`）：它在画面里找到红球，还借深度估计出红球在 x 约 0.78 米处。
接着让小车原地左转，转的时候读陀螺仪：竖直方向的转速大约 0.6 弧度每秒，停下以后回到 0。

## 背后的道理

机器人身上的相机给出它自己视角的画面。
查看器里的默认视角是给我们看的，机器人自己只能看到它摄像头里的东西。
按颜色找东西是最简单的视觉：挑出颜色对的像素，连成一块，再用深度算出它在哪。
红球真正的中心在 0.8 米，估计差了 2 厘米，因为摄像头只看得到球朝着它的那一半。
IMU（惯性测量单元）测三样东西：加速度 accel（米每二次方秒）、转速 gyro（弧度每秒）、姿态 orientation（一个四元数）。
机器人靠它知道自己是不是在倾斜、在转弯。
命令是每秒转 1 弧度，陀螺仪测到只有 0.6 左右：原地转弯时轮子会打滑，测量结果比命令更可信。
机器狗的脚上有触觉传感器，机械臂的末端有位置传感器，所有读数都是可以记录、可以比较的数字。

## 自己动手

让小车慢慢转，直到蓝箱子出现在摄像头画面的正中间。
让 agent 加一只机器狗，边走边看四只脚的触觉读数怎么交替变化。

## 怎么算成功

前置摄像头的画面里能看到前方的红球，`find="red"` 找到的物体是 ball。
转弯时 `rover/gyro` 的第三个数明显大于 0，停下后接近 0。

## 挑战

只用摄像头画面判断方向，让小车开到红球跟前停下，说说你是怎么判断该往哪边转的。
