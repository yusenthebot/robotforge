# 第 7 课 写自己的脚本：让小车走一个正方形

目标：拿到一段看得懂的 Python 脚本，让小车闭环走一个正方形，运行它，再改它。

## 你可以这样说

> 帮我写一个 Python 脚本，让小车走一个边长 0.5 米的正方形，代码要让我看得懂。

## 你会看到

agent 写一个脚本保存为 `behaviors/square.py`，然后运行。
脚本每到一个角就打印位置和朝向，作者电脑上的输出是：

```
corner 1: x=0.54 m  y=-0.03 m  heading=89 deg
corner 2: x=0.57 m  y=0.50 m  heading=179 deg
corner 3: x=0.04 m  y=0.54 m  heading=-91 deg
corner 4: x=0.00 m  y=0.01 m  heading=-1 deg
ended 0.01 m from the start
```

## 脚本长什么样

```python
from robotforge.script import connect

sim = connect()  # 连上正在运行的世界
start = sim.position("rover")  # [x, y, z]，单位米
sim.move("rover", speed=0.2)  # 开始往前开，直到 stop
while ...:  # 一边开一边量
    sim.step(0.02)  # 让仿真时间走 20 毫秒
sim.stop("rover")
print(sim.heading("rover"))  # 朝向，单位度
```

完整的脚本不到 50 行，每个函数都有注释，可以用 `read_script` 让 agent 再给你看一遍。

## 背后的道理

脚本就是一个循环：读世界、做决定、发命令。
robotforge 让脚本和仿真同步运行，只有脚本调用 `step()` 时时间才往前走，所以脚本可以慢慢想，世界不会跑掉。
开环的做法是“开 2.5 秒，转 2 秒，然后祈祷”。
闭环的做法是一边开一边量：真的走够 0.5 米才停，指南针真的转到 90 度才停，所以轮子打滑也不怕。
转弯用的是比例控制：离目标朝向越远转得越快，越近越慢，最后稳稳停在目标上。
脚本是世界文件夹里的一个文件，你可以自己改、反复运行，不需要 agent。

同一个世界一次只能运行一个脚本，避免两个脚本同时推进仿真时间。
脚本退出、取消或超时后，运行器会回收它管理的子进程树，并为输出收尾设置时限，随后释放仿真时钟。
脚本仍是本机的普通 Python，不是安全沙箱；主动脱离进程组的 POSIX 后代进程不在自动回收范围内。
已经开始的线程内规划只能等待其自身返回，不能用取消请求强制终止。

## 自己动手

把边长改成 1 米，或者把正方形改成三角形（每个角转 120 度）。
把转弯的比例系数改大或改小，看看会不会转过头。

## 怎么算成功

`run_script` 返回 `ok: true`，没有报错信息。
打印出的四个角离 0.5 米正方形的四个角不超过 0.1 米，最后回到起点附近。
