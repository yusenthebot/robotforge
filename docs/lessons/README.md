# 学习路线：九节课入门具身智能

每节课是一个你可以直接对 agent（Claude 或 GPT）说的目标。
agent 会搭好机器人、打开 3D 查看器、一步一步做给你看，并顺手讲清楚背后的道理。
每节课 10 到 20 分钟，按顺序学最顺，也可以挑感兴趣的先学。

## 怎么开始

先按 [README](../../README.md) 装好 robotforge，然后对 agent 说：

> 教我第 1 课。

agent 会调用 `lessons` 工具拿到这节课的教学计划。
在 Claude Desktop 和 Claude Code 里，也可以直接从提示词列表里选 `lesson_1` 到 `lesson_9`，或者选 `start` 先听一段导览。
每节课页面上的“你可以这样说”是原话，复制过去也行，用自己的话说也行。

## 课程

| 课 | 主题 | 你会学到 |
|---|---|---|
| [第 1 课](01-joints-and-actuators.md) | 关节和舵机 | 自由度、关节范围、舵机为什么像一根弹簧 |
| [第 2 课](02-drive-a-rover.md) | 开一台小车 | 差速转向、速度和角速度的单位、测量比假设可靠 |
| [第 3 课](03-dog-walk-and-gait.md) | 让机器狗走起来 | 步态、支撑相和摆动相、腿部逆运动学 |
| [第 4 课](04-ik-pick-and-place.md) | 逆运动学和抓取 | 正运动学和逆运动学、工作空间、抓取的动作顺序 |
| [第 5 课](05-sensors-and-camera.md) | 传感器和相机 | 机器人视角、IMU 的三种读数、触觉传感器 |
| [第 6 课](06-pd-lqr-mpc.md) | PD、LQR 和 MPC 比一比 | 反馈控制、线性化和最优增益、预测控制的代价 |
| [第 7 课](07-your-own-script.md) | 写自己的脚本 | 开环和闭环、比例控制、可以反复运行的行为文件 |
| [第 8 课](08-train-a-policy.md) | 训练一个策略 | 强化学习、奖励、策略、学出来的和设计出来的对比 |
| [第 9 课](09-import-a-urdf.md) | 导入你自己的机器人 | URDF 的结构、导入体检报告、固定基座和浮动基座 |

## 学完之后

你可以描述任何想要的机器人和任务，让 agent 帮你搭出来、动起来、比一比不同的做法。
所有世界都保存在 `~/robotforge/worlds/` 里，脚本在每个世界的 `behaviors/` 文件夹里，可以脱离 agent 自己运行和修改。
