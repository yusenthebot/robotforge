# 第 3 课 让机器狗走起来：什么是步态

目标：让一只四足机器狗在草地上走起来，能解释小跑步态，以及支撑相和摆动相。

## 你可以这样说

> 给我一只四足机器狗，放在草地上，让它往前走 10 秒。

## 你会看到

agent 新建一个草地世界，放进一只 12 个舵机的机器狗，打开查看器。
它先查一下这只狗的最高速度（模板狗大约 0.36 米每秒），再让它以 0.25 米每秒走 10 秒。
作者电脑上它走了 2.5 米，一直站得稳稳的。
走完 agent 读一下四只脚的触觉传感器：有的脚读数大于 0，说明正踩在地上，有的是 0，说明抬在空中。
你也可以在查看器里用 W A S D 自己遥控它。

## 背后的道理

步态是腿抬起和落下的节奏。
这只狗用的是小跑：对角的两条腿一起动（左前和右后一组，右前和左后一组），所以任何时候都有两只脚撑着身体。
每只脚走一条弧线：支撑相时脚踩在地上往后蹬，摆动相时脚抬起来往前迈。
脚该放在哪里是先算好的，再用腿部逆运动学把脚的位置换算成髋、大腿、膝三个关节的角度。
走路离不开摩擦和平衡：草地比光滑地板更抓地，走得越快，每只脚用来纠正的时间就越少。

## 自己动手

让 agent 把速度提到接近最高速度，同时带一点转向，看看它会不会踉跄。
在查看器里遥控它绕一个大圈。
换成真实的机器狗：对 agent 说“加一台宇树 Go2”，第一次会下载大约 31 MB。

## 怎么算成功

`move` 返回的 `distance_m` 大于 1 米，`to.upright` 是 true（没摔倒）。
截图里狗站在草地上，位置比出发时靠前。

## 挑战

让狗走一个 L 形：先直走 3 秒，再左转走 3 秒，说说转弯时步态有什么变化。
